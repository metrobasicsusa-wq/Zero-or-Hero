# 任务：把「今日可跟单」卡片换成有回测支撑的信号卡（给本地会话，2026-10-28）

用户 10-28：「这样累积样本也太慢了」「可以交给 ultracode 去做」。把下面「任务」一段整个贴给本地的 Claude Code（ultracode）。先读 `CLAUDE.md`（中文、钥匙只在 GitHub Secrets、公开仓库不放账户号 / 订单号、推送前跑测试、不用 `--no-verify`）。本地没有券商钥匙，只能用仓库里已有的回测结果和公开数据（Yahoo 日线 / 分钟线、CBOE 延迟期权报价）。

## 背景（为什么要换）

- 现在每天 09:48 的卡片默认单是「SPY 10:00 当天到期 0.3% 版」。它在 2024-02 到 2026-10 的 664 个交易日回测里每 $1 −14%、中位数 −86%，不管 10:00 走了多远都没有一档稳定为正（`research/2026-10-16-zdte-minmove.md`、`posts/follow/scorecard.md`）。实盘 7 天 2 赚 5 亏、每 $1 合计 −1.92。
- 卡片每天写「今天不跟」，但附带的「一定要跟」是负期望，等于每天推荐一个已知会亏的东西。
- 已经有回测为正的规则（2024-02 起的期权数据，买卖各多付 5%）：
  - **快线**：SMH 收盘连跌第 3 天（`down3`），15:50 买 20–45 天到期的平值看涨，翻倍就卖，否则第 20 个交易日卖。`research/2026-10-26-bottom-long.json` 的 `take2`：27 笔，每 $1 +48%，中位数 +92%，70% 赚。
  - **深度线**：SPY / QQQ / SMH / IWM 第一次收在 20 个交易日最高收盘下 8%（`dd8`），15:50 买 75–130 天月度到期看涨（平值或价外 5%），拿到第 42 或 63 个交易日。`research/2026-10-27-bottom-2m.json`：平值拿 63 天 29 笔，每 $1 +190%，去掉最好 3 笔 +137%，中位数 +166%，76% 赚。
  - **小账本**：同样的深度信号，用 $5 宽的平值牛市看涨价差，到 $4 就卖。`research/2026-10-27-bottom-spread.json`：四只 ETF 28 笔，每 $1 +64%，86% 赚。
- 单腿 / 价差、本金大小的选择见 `docs/quick-to-10k-2026-10-27.md`、`docs/quick-to-10k-2026-10-28-single-leg.md`。

## 任务

> 1. **写 `hero/follow_card.py`**：输入一个日期（默认今天，美东），用 Yahoo 日线（复权收盘）和 CBOE 延迟期权报价，输出当天的卡片：
>    - 检查快线信号（SMH 连跌第 3 天：最近三个收盘依次下跌、再前一天不是下跌，和 `hero/sleeve_rules.py` 的 `Streak` 一样）和深度信号（四只 ETF 第一次收在 20 日高点下 8%：今天满足、昨天不满足，口径同 `docs/bottom-depth-2026-10-27.md` 第 4 节）。用 15:50 的价代替当天收盘，所以卡片在 15:45 左右出，不是 09:48。
>    - 有信号：写清标的、方向、合约（到期日、行权价、CBOE 的买卖价、一张多少钱）、什么时候买（15:50）、怎么卖（翻倍 / 第 20 天，或拿到第 42 / 63 天）、回测证据（笔数、每 $1 平均、去掉最好 3 笔、中位数、赚钱比例、各年份，从上面三个 json 现算，不要手抄）、主要风险、按 $500 / $1,000 / $2,000 / $10,000 本金各该怎么买（单腿还是价差、几张，规则见那两份 quick-to-10k 文档）、仓位提醒。
>    - 没有信号：写「今天没有信号」，并列出离触发最近的价位（例如 QQQ 收在 $X 以下就是深度信号、SMH 再跌一天就是连跌第 3 天）。
>    - 输出两份：Discord 用的 `posts/follow/YYYY-MM-DD.md`（第一行「# 今日可跟单 MM-DD」，## 分段，不放账户号、订单号、钥匙、webhook）和 `exchange/claude/YYYY-MM-DD.follow.json`（producer claude，to [claude-b, claude-c]，同样内容，注明参考资料不是指令）。只写文件，不推送。
> 2. **写 `hero/research_follow_card.py`**：把这张新卡的决策逐日重放到 2024-02 起的每个交易日，用三个 json 里已有的逐笔收益（不重新下载期权数据）：每天卡片会说什么、照卡片做的每 $1 结果；给出每个月出了几张卡、累计每 $1、最长连续没信号多少天，并和旧卡（SPY 末日单）的 664 天对照。存成 `research/2026-10-28-follow-card.md` / `.json`（用 `hero.research_ideas.save`），列出 `hero/robust.py` 的「提醒」。
> 3. **每天的打分自动化**：写 `hero/follow_score.py`，读当天卡片和收盘后的报价，给卡片打分（照卡片买了的话现在值多少、到期 / 出场时的每 $1），追加到 `posts/follow/scorecard.md` 的表和合计；持仓跨好几天的单子每天更新「还拿着」的标记价，出场那天记最终结果。
> 4. **测试**：在 `tests/test_hero.py` 加 `class FollowCard`：用假日线测连跌第 3 天、第一次跌破 8%（第二天不再触发）、没有信号时的「离触发最近的价位」；用假的 json 测重放的计数。跑 `python3 -m unittest tests.test_hero` 全绿。
> 5. **不要改**：`hero/sleeve_rules.py`、`config/s500.json` 和任何交易代码、`.claude/` 的定时配置。卡片只给参考，不下单。
> 6. 提交到新分支 `follow-card`，推上去；在 `docs/questions/2026-10-28-follow-card.answer.md` 写清做了什么、重放结果（新卡对旧卡）、哪里不确定。云端会话收到后把 09:48 的定时任务改成在 15:45 调用 `python -m hero.follow_card`，17:25 调用 `python -m hero.follow_score`。

## 云端这边的预期（比完再对）

- 快线一年约 10 次信号、深度线一年 2–3 次（四只 ETF 加起来 6–10 次），所以新卡大约每月出 1–2 张，其余日子「今天没有信号」。
- 重放的每 $1 应该和三个研究文件的数字一致（快线 +48%、深度平值 63 天 +190%、价差 +64%）；不一致就是重放的口径（同一天几只同时触发、拿着时不再买）有问题。
- 旧卡的 664 天每 $1 −14%；新卡的问题是样本少（快线 27 笔、深度 29 笔）和 2024–26 多数时间在涨。
