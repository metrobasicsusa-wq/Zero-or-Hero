# 每日档案：长期研究的做法

模拟盘研究，只记录，不是投资建议。用户 2026-11-19：「应该从过去每天都学然后今天再看」；又说「这个部分我选择长期」「我的意思这里期权都选择长期的了」——这条线里凡是用到期权，都选到期远的（一个月、三个月），不用当天到期的。我第一次把这句话听成了「长期研究」，这页是那时写的；做法照用，期权一律按到期远的查。

## 这条线研究的是什么

先把过去每一天按同一套办法记成档案，今天来了再拿去对：过去长得一样的日子，后来怎么走。目的不是猜对某一天，是弄清楚哪些事能提前知道、哪些不能。

第一版（11-19）的结论，作为起点：

- 方向学不出来：收盘在开盘价上方、反着缺口走、10:00 以后接着走，三问都不比底数准。
- 幅度学得出来：开盘时问「今天收盘对昨收会超过 1% 吗」，比只报底数准 19%。
- 它漏的是平静里突然来的第一下；它会说的是「已经乱了，今天多半还乱」。
- 照它点名去做「10:00 顺着方向买」，不比现在的条件（10:00 离开盘 0.5% 以上）好。

## 每天做什么

| 时间 | 做什么 | 写到哪里 |
|---|---|---|
| 09:15 早盘 | `python -m hero.daybook read <缺口>`，缺口用盘前价对昨收 | 当天的 morning.json |
| 10:00 以后（午盘） | `python -m hero.daybook read <缺口> <10:00 对开盘>` | 当天的 midday.json |
| 收盘 | `python -m hero.daybook build` 更新档案和记分；把早上的读数和实际对一遍 | 当天的 close.json，收盘总结加一行 |

## 每周做什么（周六）

- 报这一周每天的读数和实际，累计的记分（档案对底数）。
- 一次只试一样新东西（见下面的清单），试之前写死及格线，试完不管过不过都记下来。
- 不调已经定下的标签、放宽顺序和问题。

## 研究清单（按顺序，一次一样）

1. **收盘后这一档**：今天全天的样子定了以后，明天会不会大、往哪边。和早上那几问一样走历史记分。
2. **只押幅度的做法**：档案点名的日子，10:00 同时买看涨和看跌，用一个月和三个月后到期的（`hero/research_daybook_long.py`，11-19 第一次跑）。先查清楚「知道会大」到底值不值钱。
3. **平静里的第一下**：档案漏掉的那些日子（比如 11-05 读数只有 10%）之前，有没有什么是早上就看得见的。这是账本最赚钱的那种日子，也是最难的一问。
4. **多加一样早上知道的东西**：VIX 的水平和变化、是不是数据日或到期日、开盘头半小时的成交量。每次只加一样，加了以后走历史记分要比第一版好才留下。
5. **12:00 这一档**：现在只有开盘和 10:00。
6. **别的指数和个股**：QQQ、IWM，然后是股票池里的股票。

## 规矩

- **先写线，再看数。** 每个问题过线 = 走历史记分时前后两半都比底数准，全期至少好 1%。和钱有关的做法，用真实期权价、到期远的期权；线是：点名的日子扣掉 5% 成本平均为正、去掉最好 3 天仍为正、前后两半都比其余日子好、至少 60 天。
- **一条线过了，先拆开看。** 把它和已有的条件分开，多出来的那部分不赚，就不算新东西（11-19 的教训）。
- **版本只加不改。** 第一版的标签和顺序冻结。新做法叫第二版，和第一版、和底数并排记分。
- **不拿它下单。** 要变成规则，得先过线、再放到别的指数上看、再由用户决定。
- **没过线的读数只当描述**，写的时候注明。
