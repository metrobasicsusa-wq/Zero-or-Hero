## 实现（hero/sleeves.py + hero/sleeve_rules.py，config/s500.json 的 sleeves，开关 enabled）
- 撒网 $500 版买 3 只、$1,000 版买 5 只；低开、急跌各最多 2 只；财报正股 / 两倍每天最多 3 只（期权定价波动最大的）；10-19 起所有账本都不买会拿过该股财报的单股期权（hero/sleeves.py report_inside）；周内趋势随机挑 3 只（按周固定的随机种子）、动量 1 只、新闻 3 只。
- 期权单只能是当天有效：多天的止盈单每天重新挂。

## 实现要点
- 每个账本自己的现金和持仓账（同一合约被几个账本同时持有时，券商合成一笔，按 client_order_id 前缀和数量分回各账本）。
- 账本之间不能借钱；公共资金池只用于归零 / 成功后重开。
- 网页加「各方向」表：余额、本轮盈亏、烧了几轮、成功几轮、和回测预期比。
- 每周日自动周报。
- TSLA/NVDA 价差影子记录（zdte_shadow）保留，作为真实成交的对照。
