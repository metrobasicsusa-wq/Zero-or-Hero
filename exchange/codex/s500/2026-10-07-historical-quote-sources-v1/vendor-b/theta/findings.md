# ThetaData official documentation findings

Documentation-qualified candidate; not procured, entitled, installed, or data-validated.

Options Standard, published at $80/month for individuals, is the lowest documented tick tier if the intended use qualifies under the applicable personal/nonprofessional agreement. Otherwise obtain business terms and pricing. Value, published at $40/month, supplies one-minute snapshots if that granularity is acceptable.

Use /v3/option/history/quote with interval=tick, the actual underlying root, and one historical date. Discover quoted contracts for each date with /v3/option/list/contracts/quote, then verify available dates using /v3/option/list/dates/quote.

Python>=3.12 SDK with API-key support >=1.0.9 usesHTTPS auth/gRPC data without a terminal; REST docs require local v3 terminal+Java>=21. Neither transport tested.

Published history spans the requested 2026 dates in principle; actual date and symbol completeness remain unverified. Historical contract discovery is activity-based, not a proven complete point-in-time listing master. Size units, corrections, adjusted-contract lineage and timestamp semantics need confirmation.

Confirm the agreement applicable to the chosen API subscription and whether it authorizes the intended historical retention, personal research, managed-cloud processing and authorized users. General restriction language appears alongside documented API/download products; its application to the intended workflow remains unresolved.

No account creation, authenticated request, market-data request, purchase, sample-file download, SDK installation or terminal launch occurred. All 16 documentation responses were HTTP 200.
