# ORB 缺失开盘历史的严格排序上界

`coverage_bounds.py` 单独实现 `certify(prepared, opening_market, ranked, strict_diagnostics)`。它不改严格排名，不填零、不估算缺失 bar，不把缺失股票删除后宣称全市场完整。输出 `bounded-coverage.json` 保存全部原始缺口、每个证明、未解决缺口和独立 coverage，供明确标注的数据缺口敏感性研究使用。

对今日开盘已知且价格 > 5 的候选，令 V 为今日首5分钟量，S 为已知的前14个同刻、按今日已生效拆股调整后的量之和。未知的历史成交量均非负，所以真实 RV = 14V/(S + 未知量之和) ≤ 14V/S。当 S > 0 时，这给出严格上界。若上界 < 1，候选一定不合格；若已知至少20个合格候选，且该股票的 (-RV上界, symbol) 排序键严格在已知第20名之后，则它无论未知量是什么，都无法改变top20。

使用 `fractions.Fraction` 从数值的十进制表示计算，拆股按 new_rate/old_rate 精确相乘；仅回调历史日 < 生效日 ≤ 决策日的公司行动。RV恰好等于门槛或第20名时，分别按 >= 1 和 symbol并列规则处理。已知股票的精确合格集合与top20顺序还需与严格float输出一致，存在数值分歧就不认证。本次无此类分歧。

当前开盘缺失无法限制 V，因此不认证；S = 0（包括全部历史缺失）时，RV可能无界或未定义，因此不认证；无法映射拆股也不认证。无成交bar缺失究竟代表真实零成交、停牌或来源问题，仍不作推断。

全量190评价日的结果：

- 严格来源完整：0日。
- 可以证明top20与任何非负缺失历史量取值一致：62日；另128日仍未认证。
- 原始1,484个缺口全部保留：1,001个由 RV 上界 < 1 排除，272个由第20名排序上界排除。
- 未解决211个：149个当前首段缺失，62个历史缺失但仍可能进入top20。
- 原先48日子样本中28日可认证；242个缺口剩27个无法排除。

13项合成测试通过：严格阈值、20名 cutoff、同RV不同代码的并列次序、正反拆股因果口径、全部历史缺失、当前缺失、零当前量、无效历史bar、未知量取多组非负值不改变已证明排名、严格排序不一致拒绝，以及输入不变。另15项独立下载和资金执行审计全部通过。

这里的 `ranking_complete` 是**top20可证明不受缺失量影响**，不是 `source_inputs_complete`。原始6路严格路径必须保留；跳过未认证日期的6路只能标为缺口防护敏感性，不是原协议全年完成、更不是前向验证。该模块没有收益、持仓或下单操作。
