# Independent final audit: EP event model v2

All **1,848 saved results** reconcile with the frozen protocol, source archives and exact cash arithmetic. No blocking unresolved implementation or reconciliation discrepancy was found. The audit supports consistency of the stated conditional models; it does not certify market completeness, execution or a profitable strategy.

The frozen grid retains **1,752 isolated cases and 96 portfolios**, all two-mode/12-parameter combinations. All **52 tests** passed before the first recorded v2 historical outcome run: 32 implementation tests and 20 independent tests. Code/test hashes and time ordering were checked. The independent tests cover exact evidence coordinates, nanosecond rejection, both strict source-coverage flags, mandatory execution minutes, later gap stops, malformed bars, empty sessions, corporate-action priority, stale marks, fixed budgets, T+1, daily selection and unchanged original unknown guards.

Every saved result passed the independent account verifier: whole-share intent quantity, observed signal/entry/exit references, costs, settled cash, sale receivables, T+1, daily marks, MA inputs, drawdown and milestones. The v1 verifier was adapted only to admit the newly specified null terminal value for a stale censored holding; it does not replace that null with a realized or certified value.

The extension audit checked **104,827 skipped-minute appearances in 81,325 recorded spans**, including exact whitelist coordinates or complete-request permissions and mandatory-execution exclusions. Counts overlap repeated models and are not independent market events. It checked **420 stale snapshots**, **12,558 eligible snapshots** and **468 excluded snapshots**. Timestamp freshness is separate from permanent model conditionality. Skips never create prices, quantities or cash.

All **48 isolated summary groups**, all **96 portfolio summaries**, the full **1,079-row original candidate registry**, every daily retrospective cohort ranking/selection, and all v1-to-v2 status transitions were recomputed. The original **428 complete v1 cases** have identical cash, profit and original trade fields in both new modes. All **21 parent baseline hashes** remain unchanged; old versions and news classifications were not rewritten.

The independent source pass rechecked **246 raw pages, 1,353,239 bars and 3,823 unique requested symbol-sessions**, including page chains, hashes, exact-minute timestamps and assembled values. There are **137,731 unreturned minute-grid slots**. Stored request completion does not prove exhaustive historical market events; the provider-event mode remains an explicit assumption, not an extrapolated validation from 36 examples.

The **48 original full-universe/candidate-guard paths remain incomplete with null profit and terminal wealth**. Both evidence-gated retrospective cohorts also remain incomplete (24 paths). The provider-event **market73 paths are all still holding positions (12 paths)**, with null realized profit. The provider-event **verified-news32 paths are all closed conditional models (12 paths)**, with independently reconciled ending model equity **$273.007718–$392.30761550**, below their hypothetical $500 starts. These retrospective cohorts do not replace the unknown full-market strategy or establish historical implementability.

Pre-run review identified and resolved nonzero submicrosecond timestamp acceptance, empty-session detection with only nonregular keys, and a conflicting legacy conditional flag. Regression tests passed before results. No post-result parameter or label adjustment was made by this audit.

Current symbol mapping, source clock disagreements, current historical revisions, original stock-universe/day-open screening omissions, company-action coverage and actual broker stop/fill behavior remain unresolved research limits. Observed fresh daily drawdown excludes stale/unresolved snapshots and unobserved intraday risk; a modeled liquidation milestone is not settled-cash attainment. Data stops, budget skips and censoring are not evidence of bankruptcy or a restart condition.
