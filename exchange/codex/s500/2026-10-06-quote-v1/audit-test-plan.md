# 独立报价可行性审计计划

本阶段仅验证在已冻结的诊断样本和决策时点上，SIP 报价是否足以支持后续执行模型研究。不改之前12条不完整资本路径，不创建年度收益或新财富路径。所有独立自动化测试mock网络，原始行情只读。

## 数据与因果边界

1. 输入点必须从被冻结清单读取：此前所有入场symbol-day与前10个按日期排序的已认证排名日top20；跨参数共用样本要去重但保留所有来源关系。完成交易与未解决持仓同时保留，不能只抽取盈利/完整样本；09:35排名使用第一段已完成bar，仍有行情传输/计算延迟未建模。
2. 决策时间和quote t应转换为整数纳秒。不能用截为微秒的datetime误接纳决策后不到1微秒的报价。测试恰好决策时点、未来1ns、恰好1秒/5秒和多1ns、纽约DST、跨日时区表示。
3. 先按 t <= decision 选**最新原始事件**，再验有效性。最新事件无效/撤价/条件不支持/过期时拒绝；禁止回退到更早的好报价。不能使用窗口内平均值或第一条未来报价。相同最大时间戳的不同状态若无文档可核实先后，必须拒绝为歧义；完全相同重复可折叠。
4. 正bid/ask、bid<=ask、正双边显示size、已核实regular conditions、1秒主门槛和5秒敏感性分别测试。NaN/Infinity/bool/字符串/缺字段、交叉价、单边撤价、零size、未知/混合condition不能悄悄合格。锁价是否接受须与冻结规则一致。价格和数量单位独立核对文档，未核实不能声称深度足够。
5. 没有前60秒事件只代表查询窗口中无观测；不等于现实中无报价或流动性为零。最新事件时间不是市场数据到达时间，未验证receipt时延，也不保证证券没有中途halt或book遗漏。

## 下载器与缓存

- 固定只读stock quotes endpoint；symbol正确编码，参数白名单，SIP来源，HTTPS、拒绝重定向，不输出凭据。
- 请求[decision-60s, decision]且本地再次按精确纳秒过滤；返回未来/窗外事件须计数并隔离。
- 多页全部合并后才选最新事件；不可在首张页提前认定无报价/过期。跨页同timestamp不随便丢；响应symbol/结构检查。
- 每页绑定完整请求摘要（含page token）；完整manifest逐页hash/size可核验。中断恢复不重抓已校验页；token循环、页面上限、缺页和旧格式没有链绑定应明确失败，不生成成功诊断。
- 缓存的端点/symbol/日期窗口/参数/来源必须匹配冻结point；partial cache不冒充完成。所有失败points保留。

## 算术与报告

- spread = ask-bid，spread/stopdistance = spread/(0.1*ATR14)，不要把ratio当百分比；ATR必须来自相应日之前的筛选输入。
- 用整数股数/精确十进制预算比较计算250与500美元 ask 单边可购数量，测试恰好边界与低于1股；明确是否排除费用。屏幕所示size比较须先统一单位；够size仍不保证成交。
- ask-vs-minute-entry用原已冻结minute open，仅是不同报价/成交价的比较；报价缺失不补minute open。
- 同时按ask买和bid卖只是静态跨价差诊断；数量相同，必有非正毛结果。若加费用须说明每边费用，不能用假想bid恢复本金或声称fill。
- 样本计数区分query points、unique symbol-days、quote rows、共享参数重复；1秒与5秒是嵌套同样本，不能合并成独立验证。first10 chronological selection是局部时期，不代表全年。
- 保留所有无报价、过期、无效、条件不支持与时间歧义。有效报价子样本的价差分布存在可观测性选择偏差，不能外推全年的资金表现。
