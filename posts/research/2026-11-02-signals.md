# 测试：哪些 11:30 的信号对下午说得上话（11-02）

模拟盘研究，不是投资建议。全文：research/2026-11-02-signals.md

**结论：没有一个信号在验证期站得住。20 个 11:30 前能算出来的信号，在 2019–2024 挑出「偏空档」后放到 2025–2026 看，没有一个让下午收跌的比例比基线（47%）高出 8 个百分点；把票数加起来也没信号；按票数买当天到期的看跌或看涨，每 $1 亏 28–36%。指数层面的盘中形状不是我们该找信号的地方。**

## 怎么测的

- 目标：SPY 11:30 到 15:30 的涨跌。训练 2019–2024（1,489 天）、验证 2025–2026（459 天），偏空档 / 偏多档只在训练期挑，验证期只读。
- 20 个信号：前 5 天涨跌、昨收对 20 日均线、昨天下午、开盘跳空、第一小时成交量对 10 天、10:30 和 11:30 对开盘、上午高点在 10:00 前、VIXY 对上午低点和对昨收、等权 RSP 减 SPY、消费金融减科技芯片、TLT、GLD、周一、周五、FOMC 当天和前一天、选举前一天、月度期权到期日。
- 期权：票数 ≤ −3 的日子 11:30 买 SPY 当天到期看跌、≥ +3 买看涨，离现价 0.3%，3 倍止盈 / 15:30 平。

## 结果

| 信号（验证期最好的几个） | 偏空档 | 训练期收跌 | 验证期收跌 | 比基线高 |
|---|---|---|---|---|
| 11:30 对开盘 | 低 | 47% | 52% | +4.8 个百分点 |
| 昨天下午 | 高（昨天下午涨） | 46% | 51% | +4.3 |
| 等权 RSP 减 SPY | 中 | 45% | 51% | +4.0 |
| 月度期权到期日 | 是 | 51% | 50%（20 天） | +3.2 |
| VIXY 对昨收 | 高 | 48% | 50% | +2.9 |
| TLT 开盘起 | 低 | 47% | **36%** | −10.4（反了） |

| 票数（偏空档数减偏多档数） | 训练：天数 / 下午平均 / 收跌 | 验证 |
|---|---|---|
| ≤ −3（偏空） | 611 / −0.05% / 50% | 172 / +0.08% / 45% |
| 0 | 162 / +0.08% / 41% | 40 / −0.17% / 68% |
| ≥ +3（偏多） | 184 / +0.12% / 33% | 61 / −0.04% / 48% |

- 训练期看起来像信号的（票数 ≤ −3 收跌 50%、≥ +3 只 33%），到验证期全平了（45% 对 48%）。这就是过拟合的样子。
- 两两组合里验证期最高的「昨天下午涨 + 10:30 低于开盘」62% 收跌（47 天），训练期只有 46%——两边不同向，不算。
- 期权：偏空日看跌 256 张平均 −30%（去掉最好 3 笔 −33%，各年份全负），偏多日看涨 94 张 −28%。
- 10-30 那天票数 −5、下午 −0.77%，看着准，但整张表说那是巧合。

## 要记着的

- 设计上的一个弱点：是 / 否类信号的「否」档也投票（比如「不是 FOMC 日」算偏空），把票数撑大了；单个信号那张表不受影响，结论也不受影响。
- 下午 11:30 到 15:30 平均接近零、收跌 44–47% 是常态；任何 60% 以上的格子先看天数。
- 信号该往哪找：指数层面的盘中形状这条路今天走完了——四期（孪生日、VIX 背离、止损、信号）都是五五开或负的。有过结果的是公司层面的前因（10-30 MRVL 看跌 +500%、今天 ORCL / MRVL 的供给冲击）和肥尾的账本设计（今天的 hero）。下一步把力气放在「盘前就知道的公司利空 / 利好」怎么选、怎么进上，不再找指数的下午规律。
